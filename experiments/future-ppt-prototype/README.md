# Future PPT · 播放器可行性验证

这是需求文档中“作品协议 + 时间轴播放器”的第一轮原型，不含 AI 生成接入。

## 运行

直接用浏览器打开 `index.html`，无需安装依赖或启动服务。

- 播放、暂停、拖动时间滑块，支持 1× / 4× / 10×。
- “查看跨页运动”从 57 秒播放，60 秒切换页面，绿色方块持续运动。
- 选中对象后拖动、方向键移动、输入坐标或整体左移 5px。
- 双击文字弹出文本编辑框；检查器也能改字。
- 检查器修改动画开始时间、持续时长和 X 终点偏移。
- 撤销、重做；导出 JSON 后可重新导入。
- 全屏进入演示状态，空格暂停/继续，Esc 退出。

## 本轮协议约定

所有时间以毫秒表示。页面区间连续、无重叠、覆盖整份作品，区间按左闭右开解释，整份作品的最后一帧仍保留最终可见对象。

对象在全局列表中声明，可通过 parentId 组成分组，页面不拥有对象。分组由 DOM 层级继承变换与透明度。四类对象为 text、shape、image、group；样例图片是用于验证加载和透明度动画的内嵌像素资源。

layout 的 x/y 是静态基准，位置轨道的 x/y 是相对偏移。因此整体移动 5px 只改基准，起点和终点会一起移动。修改终点只改轨道最后一个关键帧。

localTime = clamp(globalTime - start, 0, duration) * speed + localOffset

绑定区间外保持轨道首尾状态，可见区间单独控制是否显示。插值支持 linear 和 easeInOut，关键帧上的 easing 控制到达该关键帧的区间。同一对象的同一属性仅允许一条轨道。修改播放时长按比例调整 speed，保留轨道内容。

`FuturePpt.evaluate(document, time)` 无时钟、无累计增量，也不修改输入。播放器只用浏览器时钟计算当前全局时间，每帧通过同一函数求值。seek 与顺序播放共用该函数。

导入时先 validate，校验成功后才替换当前作品。

## 结构

- src/engine.js：协议校验、插值、确定性状态计算；浏览器和 Node 共用。
- src/sample.js：120 秒作品，两个页面区间，跨页运动位于 50–70 秒。
- src/app.js：DOM 渲染、播放控制、基础编辑与 JSON 导入导出。
- tests/engine.test.cjs：Node 内置测试，无额外依赖。
- tests/browser.html：真实浏览器页面操作验证，需同源访问（或本地浏览器启用 file access）。

## 验证结果（2026-10-15）

运行 `node --test tests/engine.test.cjs`：10 项通过。

验证覆盖：协议校验、边界前后位置、前后跳帧一致性、端点保持、speed/localOffset、整体移动不影响轨道及其他对象、文本修改、终点修改、时长拉伸、JSON 往返和非法数据拒绝。

本机 Edge headless：9 项通过，覆盖十个对象渲染、跨页 DOM 实例保留、运动连续性、页面切换、微调、撤销、重做、终点编辑及图片加载。

60 秒位置为 x=590；59.999 秒与 60.001 秒之间位移为 0.098px，符合线性轨道速度，没有页面切换重置。

结论：该声明式数据结构足以支撑本轮基础对象的确定性播放、跨页连续运动和精确修改，可作为生成依赖的第一版目标格式。

## 尚未验证或实现

AI 生成质量与 SDK 易用性、复杂交互事件回放、大规模对象性能、复杂文本排版、运动路径、发布部署均待后续验证。全屏、实际时钟播放暂停与文件下载导入尚未做自动化交互验收；JSON 往返已做核心测试。

本轮编辑器是验证工具：没有缩放手柄、画布内文字编辑、吸附对齐。分组子对象可数值编辑，但暂不支持鼠标拖动，以避免未实现逆变换时出现错误位移。图像仅接受内嵌 PNG/JPEG/WebP。轨道条与时间刻度为当前样例的辅助显示，并非通用时间轴编辑器。
