推荐迁移方式（保留本项目编辑器的定制功能）：
1. 在新设备安装 Git、Git LFS、Node.js 22+（建议24）和 Bun。
2. 克隆仓库并切换到 setup/ppt-foundation：
   git clone --branch setup/ppt-foundation https://github.com/YZqwwq/HyperFrames-ppt.git
   cd HyperFrames-ppt
   git lfs install
   git lfs pull
3. 将 probation-review-editable.zip 解压得到的 probation-review 文件夹
   放入仓库 presentations/ 下，替换原有同名目录（建议先备份旧目录）。
   此压缩包是最新演示内容；本次 Git 提交仅更新程序源码。
4. 安装依赖和构建：
   bun install --frozen-lockfile
   bun run build
5. 启动：
   node packages/cli/dist/cli.js preview presentations/probation-review --port 5194
6. 浏览器打开终端输出的本地地址。

若只使用演示素材压缩包，将 probation-review 放入同版本仓库的 presentations/ 下。
压缩包包含实际字体与图片；通过 Git 克隆则必须拉取 LFS 素材。
渲染/浏览器检查需要 Chrome：可运行 node packages/cli/dist/cli.js browser ensure，
或设置 HYPERFRAMES_BROWSER_PATH 指向本机 Chrome/Edge 可执行文件。
